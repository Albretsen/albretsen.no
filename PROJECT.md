# Project: Albretsen.no

## Goal
Build and evolve the `albretsen.no` website over time with a dedicated OpenClaw project session.

## Current focus
Implement the dashboard expansion described in:
- `docs/albretsen-dashboard-design-document.md`

## Working rules
- Work in small, reviewable increments.
- Prefer the highest-priority unfinished task.
- Update project files as progress changes.
- Run lint and build after meaningful changes.
- Review diff before considering a milestone done.
- Commit stable work only.
- Do not deploy or merge without approval.
- Do not invent facts about Asgeir.

## Human-in-the-loop rules
Stop immediately and ask for input if blocked by:
- missing credentials
- unclear product/design decision
- risky/destructive action
- approval requirement
- missing access
- uncertainty that could cause rework

When blocked, send one concise message with:
- blocker
- exact input/decision needed
- recommended option
- 1-2 alternatives

Then wait.
