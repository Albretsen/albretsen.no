# Heure Bleue: vehicles

Low-poly vehicles for the Heure Bleue explorations, plus `vehicles.js`, a drop-in loader and arcade driving kit (three.js r170).
Open `preview.html` from a static server to see them all on a blue-hour stage. It has a time slider, a "Drive the hero car" mode (C switches between chase and cockpit), an animated door and a traffic loop. `preview.png` is a contact sheet.

All are my own Blender work, generated by the scripts in `src/` (`src/build.sh [name]` rebuilds and optimises; needs Blender 5.x and `@gltf-transform/cli`). No third-party models and no Meshy credits were used.

## Conventions
- +Y up, metres, origin on the ground under the vehicle's centre. **Vehicles face +Z; their left side is +X** (European left-hand drive, so the driver sits at +X).
- Files are meshopt-compressed. Load them with `GLTFLoader` + `MeshoptDecoder` (`vehicles.js` does this).
- Materials are shared by name: `paint` (body colour, recolour freely), `paint_accent`, `chrome`, `tyre`, `trim_dark`, `shadow`, `interior`, `interior_dark`, `glass`, `glass_tint`, `wood`, `canvas`...
- Lights: `emissive_headlight`, `emissive_taillight`, `emissive_dash` (gauges). Each has its emissive colour set. `prepareVehicle` sets `emissiveIntensity` to 0, and `setLights(k)` turns them up. The taillights also brighten when braking.
- Named nodes: `wheel_fl/fr/rl/rr` (cars) or `wheel_f/r` (two-wheelers), `steering_wheel` (hero; spins about its local Z), `door_l`/`door_r` (hero; origin on the hinge), `handlebar` (scooter and bike; turns about Y), `crank` (bike pedals; turns about X).
- Empty anchors: `seat_driver` (the hero's first-person eye), `seat_passenger`, `exit_l` (where the driver stands after getting out), `seat_rider` / `seat_pillion` (two-wheelers, for a seated character), `light_head*` / `light_tail*` (put real lights here).

## vehicles.js
```js
// import map: "three" and "three/addons/" -> three@0.170.0
import { loadVehicle, ArcadeCar, CarInput, ChaseCamera, PathFollower } from '../_shared/3d/vehicles/vehicles.js';

const car = await loadVehicle('hero');            // 'hero' | 'heroMustard' | 'citycar' | 'van' | 'scooter' | 'bicycle' | url
scene.add(car.root);
car.addBeams();                                    // optional SpotLights from the headlamps (hero only: they cost)
const drive = new ArcadeCar(car, { groundY: (x, z) => 0, canMove: (x, z) => !insideBuilding(x, z) });
const input = new CarInput({ touch: document.body }); // WASD/arrows, Space brake, E/Enter action; joystick + E button on touch screens
const cam = new ChaseCamera(camera, car);          // cam.mode = 'cockpit' for first person
drive.set(0, 0, 0);                                // x, z, heading

function frame(dt) {
  drive.update(dt, input.state());                 // throttle / brake+reverse / steer, no drift, clamped to groundY
  cam.update(dt);
  car.setLights(duskAmount);                       // 0 by day, 1 at night
  if (input.consumeAction()) { /* E pressed: stop, open the door, swap to the walker */ }
}

// getting out: drive.enabled = false; car.setDoor('l', 1); place your character at car.anchors.exit_l
// ambient traffic along a loop of [x, z] points:
const van = await loadVehicle('van'); scene.add(van.root);
const loop = new PathFollower(van, [[0, -40], [0, 40], [8, 40], [8, -40]], { speed: 7 });
loop.update(dt);   // wheels spin, front wheels steer, two-wheelers lean
```
- `loadVehicle(name, { paint, posterColors })`. Each call returns an independent clone with its own materials. Pass `posterColors: true` if your scene runs with `THREE.ColorManagement.enabled = false` (as design 64 does), so colours come back as the palette's sRGB values.
- `input.state()` also gives `moveX` / `moveY` from the same keys and joystick, so you can reuse it for walking after the player leaves the car.
- `ArcadeCar` options: `maxSpeed` (16 m/s), `accel`, `brakeDecel`, `reverseSpeed`, `wheelbase`, `maxSteer`, `steerRate`, `groundY`, `canMove`, `lean`. The body leans and pitches on `car.chassis`; the wheels stay on the ground.
